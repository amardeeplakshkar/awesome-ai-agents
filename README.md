## Why This List

This list focuses on AI coding agents, not a generic list of all AI agents. This one groups the agents that actually do the work - coding agents, general-purpose agents, automation agents and frameworks to build your own - so you can find the right one in seconds, without hunting across different sites.

## Coding Agents

| Agent | What it does |
| --- | --- |
| [Muse Code](https://dev.meta.ai/docs/muse-code) | Meta's terminal and CI coding agent built on Muse Spark that plans, edits and runs commands with approvals and a sandbox |
| [Claude Code](https://claude.com/product/claude-code) | Anthropic's terminal coding agent that reads a codebase, plans changes, edits files, runs tests and opens PRs |
| [OpenAI Codex](https://openai.com/codex/) | OpenAI's coding agent in ChatGPT, editor and terminal that works on tasks in parallel in cloud sandboxes |
| [Cursor](https://cursor.com) | AI-first code editor with agents across desktop, CLI, web and mobile that plan, write and review code |
| [Gemini CLI](https://geminicli.com) | Google's open-source terminal agent that brings Gemini into the terminal for coding, shell and file tasks |
| [GitHub Copilot](https://github.com/features/copilot) | GitHub's AI coding assistant and agent for chat, code review, CLI and cloud coding tasks |
| [OpenCode](https://opencode.ai) | Open-source coding agent for terminal, desktop and IDE that works with 200+ model providers |
| [Cline](https://cline.bot) | Open-source autonomous coding agent for VS Code, JetBrains, CLI and desktop, model-agnostic |
| [Aider](https://aider.chat) | Open-source terminal pair-programming agent that edits real files with any LLM and auto-commits to git |
| [Amp](https://ampcode.com) | Coding agent and dev environment that runs each thread in its own cloud machine |
| [Kilo Code](https://kilo.ai) | Open-source coding agent for VS Code, JetBrains and CLI with orchestrator mode and cloud agents |
| [Google Antigravity](https://antigravity.google) | Google's agent-first dev platform that orchestrates parallel subagents across app, CLI, IDE and SDK |

## General-Purpose Agents

| Agent | What it does |
| --- | --- |
