# Contributing to Awesome AI Agents

Thanks for helping improve this list.

## How to Add an Entry

1. Fork this repo.
2. Add an entry as one line in the right table in this format:

   `| [Name](URL) | What it does |`

3. Open a pull request.

## Rules

- The agent must be a real available AI agent.
- One entry per agent.
- No duplicates.
- Put the entry in the right section: Coding Agents, General-Purpose Agents, Automation Agents or Build-Your-Own Frameworks.
- Keep the description short and factual - one line only.
- Link to the agent's official site or docs.
